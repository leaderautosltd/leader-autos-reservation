# Leader Autos Ltd Reservation Website

A free, mobile-friendly static reservation website designed for GitHub Pages.

## Files
- `index.html` — website
- `style.css` — design
- `script.js` — reservation form
- `logo.svg` — simple Leader Autos Ltd logo

## Important
The form uses the visitor's email app to send the reservation request to `wesellcarsuk@gmail.com`. This keeps hosting free and does not require a paid database or server.

## GitHub Pages
1. Create a new GitHub repository, for example `leader-autos-reservations`.
2. Upload all four files plus this README.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the free `github.io` website address.

No paid hosting is required.
